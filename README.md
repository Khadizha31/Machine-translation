# Machine-translation

**Лабораторная работа №1**
Компьютерная лексикография, терминологические базы (TBX) и Translation Memory (TMX) в Smartcat.

**Студент:** Асадова Хадижа Эльдаровна
**Группа:** ИНФА-221
**Вариант:** 1 (предметная область: Информационные технологии: разработка ПО и DevOps)

---

### Цель работы
Научиться программно обрабатывать стандарты обмена терминологическими данными (TBX) и памятью переводов (TMX), реализовать поиск нечётких совпадений (Fuzzy Match) и подстановку терминов глоссария, а также экспортировать результат в CAT-систему Smartcat.

### Источники
Учебные материалы курса, официальная документация стандартов TBX-Core v2 и TMX 1.4b, а также библиотеки Python (`lxml`, `pandas`, `Levenshtein`).

### Полученный результат
В ходе выполнения работы был написан код на Python, который успешно справляется со всеми поставленными задачами. Программа прошла все 5 встроенных автотестов без ошибок.

**Что было сгенерировано:**
* **100 терминов** — создан валидный файл глоссария `variant_1.tbx`.
* **100 предложений** — создана валидная память переводов `variant_1.tmx`.
* Настроен алгоритм, который находит точные совпадения (Exact), контекстные (ICE) и нечеткие (Fuzzy от 75%).
* Настроена автоматическая подстановка терминов из глоссария в текст.

**Экспорт данных:**
В конце работы программа сформировала три готовых файла:
1. `glossary_smartcat_v1.csv` — глоссарий (100 терминов), готовый к импорту в Smartcat.
2. `tm_segments_v1.csv` — таблица с 100 предложениями памяти переводов.
3. `fuzzy_report_v1.csv` — отчет о найденных совпадениях.
