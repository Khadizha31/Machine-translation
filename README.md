# Machine-translation

Лабораторная работа №1: Компьютерная лексикография и TMX/TBX

**Студент:** Асадова Хадижа Эльдаровна  
**Группа:** ИНФА-221  
**Вариант:** 1 (Информационные технологии: разработка ПО и DevOps)

### Постановка задачи

Целью работы является программная обработка стандартов обмена терминологическими данными (TBX) и памятью переводов (TMX) на языке Python. В рамках задания требовалось реализовать четыре функции: парсинг TBX-глоссария, извлечение параллельных сегментов из TMX, алгоритм нечеткого поиска (Fuzzy Match) с поддержкой контекстных совпадений (ICE), а также автоматическую подстановку терминов в текст.

### Источники

При выполнении работы использовались учебные материалы курса «Основы машинного перевода», официальная документация стандартов TBX-Core v2 и TMX 1.4b, а также библиотеки Python (`lxml`, `pandas`, `Levenshtein`).

### Полученный результат

Разработан программный конвейер, который корректно извлекает данные из XML-файлов (с учетом пространств имен и вложенных тегов) и выполняет поиск по памяти переводов. Реализован алгоритм, распознающий точные, контекстные и нечеткие совпадения.

В ходе работы были сгенерированы валидные файлы данных: глоссарий из 100 терминов (`variant_1.tbx`) и память переводов из 100 предложений (`variant_1.tmx`). Все 5 автотестов пройдены успешно. Также сформированы итоговые CSV-файлы, готовые к импорту в CAT-систему Smartcat.
