## Лабораторная работа №3
Контекстный перевод и локализация с помощью LLM (Ollama / qwen3.5:9b).

### Цель работы
Исследовать управляемость перевода больших языковых моделей (LLM): сравнить режимы zero-shot, controlled и few-shot, оценить соблюдение терминологии, точечное исправление ошибок (repair), управление стилем и сравнить результаты с NMT-моделями из ЛР №2.

### Полученный результат
Реализован полный пайплайн контекстного перевода с использованием локальной модели `qwen3.5:9b` через Ollama на GPU T4. Все этапы работы выполнены успешно:
* **Терминология:** После ручной проверки подтверждено соблюдение глоссария на уровне **95.7%** в режимах `controlled` и `fewshot`, что значительно превосходит базовый `zero-shot` (91.3%) и MarianMT (78.3%).
* **Repair:** Протестировано точечное исправление терминов. Модель способна корректировать нарушения без переписывания всего сегмента (`unchanged_ratio ≈ 0.97`).
* **Стиль:** Проанализирована адаптация под академический и инструктивный стили. Выявлено, что модель сохраняет терминологию при смене стиля, но слабо меняет регистр обращения на описательных сегментах.
* **Экспертная оценка:** Принято 5 аргументированных решений по различиям переводов. NLLB показала лучшие результаты в передаче сложных составных терминов по сравнению со специализированной MarianMT.

### Экспорт данных
В конце работы сформирован архив `lab03_results.zip`, содержащий:
1. Папку `results/` с трассировкой вызовов LLM, таблицами терминологического QA, сравнением стилей и сводной матрицей систем.
2. Папку `figures/` с 3 графиками (соблюдение глоссария до/после проверки, эффект repair, сравнение стилистических маркеров).
3. Отчет `report.md` и файл зависимостей `requirements.txt`.
